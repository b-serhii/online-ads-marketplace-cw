# Online Ads Marketplace

**Тема:** Розробка вебдодатку для онлайн-біржі оголошень із системою категоризації та модерації контенту.

## Короткий опис

Online Ads Marketplace — вебзастосунок для розміщення та пошуку локальних оголошень про товари й послуги. Мета проєкту — зробити публікацію оголошень простою, а пошук пропозицій — зручним завдяки категоріям, фільтрам і модерації контенту.

Проєкт продовжує та розвиває попередню курсову роботу.

## Основні можливості

- Реєстрація та авторизація користувачів.
- Створення, перегляд, редагування та видалення власних оголошень.
- Додавання опису, ціни, категорії та зображень.
- Пошук, фільтрація й сортування оголошень.
- Адміністративне керування категоріями, користувачами й модерацією контенту.

**Заплановане розширення:** збереження оголошень в обране, коментарі та інтелектуальна категоризація контенту. Ці можливості є напрямами подальшої розробки, а не заявою про готову реалізацію.

## Потенційні ролі користувачів

| Роль | Можливості |
| --- | --- |
| **Гість** | Перегляд і пошук публічних оголошень. |
| **Зареєстрований користувач** | Публікація, редагування й видалення власних оголошень; керування профілем. |
| **Адміністратор** | Модерація оголошень, керування категоріями та обліковими записами. |
| **Модератор (можливе розширення)** | Перевірка й приховування небажаних оголошень без повного адміністративного доступу. |

## Потенційні ролі в команді розробки

- **Керівник проєкту / аналітик** — вимоги, план робіт, пріоритети.
- **Frontend-розробник** — інтерфейс і взаємодія з API.
- **Backend-розробник** — серверна логіка, API та авторизація.
- **UI/UX-дизайнер** — макети й зручність користування.
- **QA-інженер** — перевірка функціональності та помилок.

*Це можливі напрями відповідальності, а не підтверджений розподіл ролей між учасниками.*

## Технології

- **Frontend:** React, TypeScript, Redux Toolkit, Material UI.
- **Backend:** Python, FastAPI.
- **База даних:** PostgreSQL.
- **Робота із зображеннями:** Cloudinary.
- **Контроль версій:** Git, GitHub.

## Статус

Проєкт перебуває на етапі подальшого розвитку на основі курсової роботи. Актуальний склад реалізованих функцій визначається кодом у репозиторії; наведені майбутні можливості не слід вважати реалізованими до їх додавання.
